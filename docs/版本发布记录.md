# 版本发布记录

> 本文记录可审计的版本发布事实：版本号、源码提交、市场索引、CI 结果与 Git 标签。功能原理和业务行为见《[dsh-turn-summary 原理与业务流程](dsh-turn-summary%20原理与业务流程.md)》；简要变更见 [`CHANGELOG.md`](../CHANGELOG.md)。

## 发布纪律

每次发布必须同时完成以下项目：

1. `package.json` 版本号与 `CHANGELOG.md` 同步；
2. 在 `dsh-turn-summary` 创建对应的 Git tag（格式：`v<版本号>`）；
3. 在 `dsh-plugin/market/index.json` 追加版本条目，不覆盖历史版本；
4. 市场条目的 `source.commit` 指向发布提交；
5. README 的固定市场索引地址指向包含该版本条目的索引提交；
6. 本地测试与 GitHub Actions 均通过；
7. 将上述提交、链接和验证结果登记在本文。
